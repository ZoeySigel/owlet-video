# 管理后台

入口：`/?view=admin`。使用原有账号登录后，管理员可从侧栏或顶部管理按钮进入。

## 首次授权

后台使用 GCFeed 已有的 `account.role` 与 `account.status` 字段，无需新表或数据库迁移。普通账号不能通过注册、修改资料或管理接口把自己设为管理员。

在应用运行环境中，为一个已有且正常的账号授权：

```bash
# Docker Compose
docker compose exec api /usr/local/bin/owlet-video grant-admin YOUR_USERNAME

# 服务器：加载现有应用配置后，以应用用户执行
set -a
source /etc/owlet-video/app.env
set +a
runuser -u owlet-video -- /srv/owlet-video/current/bin/owlet-video grant-admin YOUR_USERNAME
```

授权后刷新页面即可显示入口，无需重启。通过服务器撤销角色时，后续管理请求立即失去权限。后台不提供任意授权或停用管理员的功能，避免误操作锁住管理入口。

## 功能

- 站点概况：账号、停用账号、展示视频、下架视频和视频文件总量。
- 账号：按用户名或 ID 搜索、状态筛选、分页；编辑用户名与简介，重置密码，停用和恢复。
- 视频：按标题、作者或 ID 搜索、状态筛选、分页；原生播放器预览、编辑标题和简介、下架及恢复展示。
- 改名、重置密码和停用账号会撤销该账号全部会话。管理员修改自己的用户名或密码后需重新登录。
- 下架不删除媒体或互动数据，不显示于站内 Feed、公开详情、作者作品及话题列表。原媒体地址仍由静态服务器提供，已知直链仍可访问；这不是文件级访问控制。恢复展示可能等待页面缓存到期或刷新列表。
- 编辑视频会重新提取话题；展示中的视频通过 Outbox 更新核心发布事件和内容向量。

## 权限与验证

每次认证请求从数据库检查账号状态及角色，不能靠缓存会话绕过停用或降权。所有 `/api/v1/admin/*` 接口需有效会话和管理员角色，跨域写入沿用全站 Origin 校验。列表不返回密码哈希、刷新令牌或会话凭据。后台操作在应用日志记录操作者、动作和目标 ID，密码不写日志。

`backend/admin_test.go` 使用独立测试数据库验证匿名与普通账号越权、角色实时生效、停用与恢复、密码重置、输入校验、搜索参数及缓存预热后的下架与恢复。前端适配桌面表格及移动端卡片列表，弹窗支持键盘关闭与焦点恢复。
