# 前端改版与验收

本次改版采用银白金属面板、电光蓝选中态和短视频网格。所有页面共用导航、按钮、头像、视频卡片、加载和错误组件；保留 API、邀请码注册及查询参数分享地址。

## 页面结构

- `frontend/src/App.tsx`：页面、查询参数路由和业务交互。`sort` 支持 latest / hot / likes / following，刷新与浏览器历史保持一致。
- `frontend/src/ui.tsx`：共享视觉组件、带清理逻辑的数据读取 Hook、面向用户的错误提示。
- `frontend/src/Publish.tsx`：保留 MD5、5 MiB 分片、三并发和续传；失败时等待在途任务完成，避免重试和旧上传任务重叠。
- `frontend/app/globals.css`：主题变量、桌面/平板/手机布局、键盘焦点及减少动画支持。低于 1024px 使用图标导航，低于 768px 使用底部导航。

首页和个人作品使用 3:4 封面；播放器使用 contain 保留视频比例。产品中没有演示数据或虚构统计。旧 Newsreader 字体依赖已移除。

## 验收结果（2026-09-19）

- `npm run typecheck` 和 `npm run build` 通过；Next.js 静态导出正常。
- 使用本机实际 API 验证首页视频、详情及视频播放，浏览器无运行时异常。测试视频原始尺寸为 640 × 800，播放器成功加载并播放。
- 对发现、播放、个人主页、账号、发布、私信联系人、私信会话、通知、设置、喜欢和话题共 11 个视图，在 390 / 768 / 1280 / 1440px 下检查，44 组布局均无横向溢出。覆盖长标题、长用户名和长评论，并检查截图。
- 使用仅存在于本地测试脚本的 API 拦截，验证排序、刷新、前进后退、分页、点赞/取消点赞、评论/删除、关注、私信发送/返回、通知已读及角标、资料保存、上传/发布、登录、退出和邀请码注册。
- 验证空列表、网络失败重试、无封面/封面失败、视频播放失败重试、错误文件格式、上传失败后复用会话续传、密码更新后保留当前会话。
- 检查减少动画设置和键盘跳转主内容；主题正文、辅助文字和主按钮文字对比度均达到 4.5:1。

## 联调边界

真实服务验收覆盖只读浏览和播放。没有使用用户凭据，因此注册、登录、上传、评论、私信、资料/密码修改以及通知已读等写操作在本地模拟接口完成；未声称这些流程已通过真实后端端到端验证。未进行生产部署。

本机验收脚本、结果和截图位于 Git 忽略目录 `artifact/frontend-qa/`，不会包含到生产构建中。预览端口 3100 使用新静态导出，API 与媒体转发至本机原服务 3000；正式运行仍按项目现有部署流程。
